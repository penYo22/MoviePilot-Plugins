# 115离线整理 (Transfer115)

> ⚠️ **免责声明：本插件未经充分测试，使用115网盘离线下载及API功能存在账号被封禁风险，后果自负，封号自理。建议在小号或测试账号上使用。**

MoviePilot 插件，通过115网盘离线下载能力自动整理媒体文件。

## 功能

- 支持两种授权方式：共用 MoviePilot 已存储的 115 OAuth 授权，或手动填写 Cookie
- 在设置页粘贴磁力/ed2k/115分享链接，保存后自动提交离线下载任务
- 定时轮询离线任务完成状态，完成后自动调用 MoviePilot 媒体识别和重命名
- 整理失败时将整个任务文件夹移动到指定的"整理失败目录"，保持文件完整
- 数据页可视化浏览115云盘目录，一键设置下载目录和失败目录（仅 MP OAuth 模式）
- 数据页实时显示授权状态及任务处理记录

## 授权方式

### 共用 MP 授权（推荐）
复用 MoviePilot 中已配置的115网盘 OAuth Token，无需额外填写任何内容。  
请先前往 **设置 → 存储 → 115网盘** 完成扫码登录。

### 手动填写 Cookie
适用于不使用 MoviePilot 存储功能的场景，在设置页填写115网盘 Cookie 字符串。  
Cookie 格式：`UID=xxx;CID=xxx;SEID=xxx`（在115网页版 F12 → Application → Cookies 中复制）

## 配置项

| 配置项 | 说明 |
|--------|------|
| 授权方式 | 选择 MP OAuth 或 手动 Cookie |
| Cookie | 仅 Cookie 模式需要填写 |
| 离线下载保存目录 | 115云盘内的绝对路径，如 `/待整理` |
| 整理失败目录 | 整理失败时整个任务文件夹移动到此处 |
| 轮询间隔(分钟) | 检查任务完成状态的频率，默认 5 分钟 |
| 整理方式 | 移动 / 复制 |
| 立即检查一次 | 保存后立即触发一次任务检查 |
| 添加离线下载链接 | 粘贴链接后保存，自动提交并清空 |

## 工作流程

```
填写链接 → 保存 → 提交离线下载任务
                        ↓
              定时轮询任务完成状态
                        ↓
              发现 status=2 已完成任务
                        ↓
         chain.recognize_media() 识别媒体
                        ↓
    识别成功 → chain.transfer() 按 MP 规则整理重命名
    识别失败 → 重试（最多3次）→ 整个任务文件夹移入失败目录
```

## 风险提示

- 频繁调用或异常行为可能导致账号被限制或封禁
