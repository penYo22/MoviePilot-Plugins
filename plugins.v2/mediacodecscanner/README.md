# 媒体编码扫描

扫描本地或挂载的媒体库目录，使用 `ffprobe` 读取视频真实编码信息，收集 Chrome 可能无法直接播放的媒体文件，并通过 MoviePilot 通知管理员。

## 功能

- 定时扫描媒体库目录
- 支持手动立即扫描
- 支持排除目录、最小文件大小、单次扫描数量上限
- 识别封装、视频编码、音频编码、分辨率和文件大小
- 提供 Chrome 默认、严格网页播放、宽松模式和自定义规则四种兼容策略
- 支持管理员选择允许/风险的封装、视频编码和音频编码
- 对新增问题文件发送通知，避免重复提醒
- 插件详情页展示最近的问题文件

## Chrome 兼容性判断

插件按浏览器原生播放能力做保守判断：

- 友好：MP4/M4V/MOV/WebM，H.264/VP8/VP9/AV1，AAC/MP3/Opus/Vorbis/FLAC
- 高风险：MKV/AVI/WMV/TS，HEVC/H.265、VC-1、MPEG-2、DivX/Xvid、DTS、TrueHD、AC3/EAC3

实际播放能力还可能受浏览器版本、系统解码器、硬件解码和服务端转封装影响。插件定位是管理员预警，不会自动转码或修改文件。

## 简单配置

普通用户只需完成以下设置：

1. 填写 `扫描目录`，每行一个目录。
2. 选择 `兼容策略`，不确定时保持“Chrome 默认（推荐）”。
3. 启用插件；需要马上查看结果时开启“立即扫描一次”。

策略说明：

- Chrome 默认：保守检查 Chrome 常见原生播放格式，适合大多数用户。
- 严格网页播放：减少不同浏览器和系统环境下的兼容性差异。
- 宽松模式：允许 HEVC、MKV、AC3/EAC3 等现代客户端可能支持的格式。
- 自定义规则：使用高级设置中的完整封装、视频和音频编码规则。

如果只需要放行或标记少量视频编码，可直接使用 `额外允许的视频编码` 和 `额外标记的视频编码`，不必切换到自定义规则。

## 高级配置

排除目录、`ffprobe` 路径、超时、扫描数量限制和完整编码规则默认收在“高级设置与自定义规则”中。选择“自定义规则”后，可调整：

- `允许封装`
- `允许视频编码`
- `允许音频编码`
- `强制风险视频编码`
- `强制风险音频编码`

例如内网环境确认 Chrome/客户端可以播放 HEVC 时，直接把 `hevc` 或 `h265` 加入“额外允许的视频编码”即可，插件会自动取消对应的风险标记。

## 使用

1. 确认 MoviePilot 容器或主机中可以执行 `ffprobe`。
2. 按“简单配置”完成设置。
3. 打开“立即扫描一次”或在详情页点击“立即扫描”。

如果 `ffprobe` 不在默认 PATH 中，请在 `ffprobe路径` 中填写完整路径。
